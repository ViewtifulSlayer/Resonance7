# Freebuff (workspace agent host)

Use this skill when the task is about **Freebuff itself** in this repo: where it reads
context from, how skills and MCP are loaded, and how to fix "Freebuff cannot see X".

Freebuff is a free, multi-product coding agent (CLI, Desktop, Web, Cloud, Chat) built on
the Codebuff framework. This workspace targets the **Freebuff client running in VS Code**.

Route elsewhere when the task is not about Freebuff:

- VS Code host behavior (`.vscode/mcp.json`, `.github/agents`, Copilot skills): use the **vscode** skill.
- Underlying framework/CLI (`knowledge.md`, `/init`, custom agents, SDK): use the **codebuff** skill.
- Querying workspace SQLite via MCP: use the **mcp-sqlite** skill.

## 1. Always-on context

- **Root `AGENTS.md`** is auto-read at session start. In this repo it is the thin,
  always-on layer; the full contract is `library/agent_foundation.json`.
- **`knowledge.md`** files add project context (architecture, build/verify commands).
  `~/.knowledge.md` is the global preferences file.
- Home-directory precedence (only the first found is used, case-insensitive):
  `~/.knowledge.md` > `~/.AGENTS.md` > `~/.CLAUDE.md`.
- Project `knowledge.md` adds to, and can override, the home file. A `knowledge.md`
  in a subdirectory scopes context to that subtree.

Keep `AGENTS.md` short. Durable protocol belongs in `library/agent_foundation.json`;
procedural detail belongs in skills.

## 2. `.agents/` layout (this repo)

```
.agents/
  skills/<name>/SKILL.md   # tracked, canonical skill packages
  mcp.json                 # local, gitignored; generated by setup_database.py
.freebuff/                 # local, gitignored; machine state (project id)
AGENTS.md                  # tracked, always-on rules (repo root)
```

- `.agents/skills/` is **canonical** for this workspace.
- `.agents/mcp.json` and `.freebuff/` are machine-local; never commit them.

Generate or refresh MCP config:

```bash
python library/tools/scripts/setup_database.py                  # writes .agents/mcp.json
```

## 3. Skills

- A skill is a directory containing `SKILL.md` (YAML frontmatter + body). The directory
  name must equal the `name` field exactly.
- Every skill becomes `/skill:<name>`; the agent can also auto-load it through the `skill`
  tool when the description matches the task.
- Discovery priority (higher overrides lower with the same name):
  1. `~/.claude/skills/`
  2. `~/.agents/skills/`
  3. `.claude/skills/`
  4. `.agents/skills/` (project, highest)
- Frontmatter: `name` and `description` required; `license` and `metadata` optional.
  Names: lowercase letters, digits, and hyphens; max 64 chars; no leading, trailing, or
  consecutive hyphens.

See `reference.md` for the full frontmatter reference and examples.

## 4. MCP

- Freebuff reads MCP servers from `.agents/mcp.json` (project) and `~/.agents/mcp.json`
  (global). The file uses the standard `mcpServers` key.
- The loader reads MCP config **once at boot, from the process working directory**.
  Reloading the window is not enough: start Freebuff from the repo root (or ensure the
  project picker targets it) and restart. See the issue link in `reference.md`.
- This repo's server key is `Resonance7-sqlite`; default database alias `session_logs`.
- MCP tools are SELECT-only. Schema or data changes go through ingest/migration scripts.

## 5. Global vs project

| Scope | Skills | MCP |
|-------|--------|-----|
| Project | `.agents/skills/` | `.agents/mcp.json` |
| Global | `~/.agents/skills/` | `~/.agents/mcp.json` |

`--global-agents` copies workspace files into the global location but never overwrites an
existing destination, so machine-local global config is preserved.

## 6. Troubleshooting

- **Skill not listed**: directory must be `.agents/skills/<name>/SKILL.md`; the `name`
  field must match the directory; name must pass the validation rules; restart Freebuff.
- **Skill not loading**: invalid YAML frontmatter (must start and end with `---`, have
  `name` and `description`, valid YAML syntax).
- **MCP server missing**: confirm you launched from the repo root, `.agents/mcp.json`
  exists and is valid JSON, uses `mcpServers`, and has absolute paths on Windows.
- **Wrong DB answers**: pass `database_path` explicitly rather than relying on the default.

## 7. Capabilities and limits (volatile)

Freebuff access tier, model catalog, and session limits change over time. Do not hardcode
model names or session counts into repo docs; state the current limits when asked and cite
the source. See `reference.md` for a dated snapshot and the pricing/model page.
